# 🎯 Number Guessing Game

A simple and interactive **C++ console-based Number Guessing Game** where the computer randomly generates a random number, and the player must guess it with the help of hints. This project is ideal for beginners learning C++ programming concepts such as loops, conditional statements, functions, and random number generation.

---

## 📌 Overview

The Number Guessing Game is a beginner-friendly C++ application that generates a secret number within a specified range. The player keeps guessing until the correct number is found. After every incorrect guess, the program provides a hint indicating whether the guessed number is too high or too low.

---

## ✨ Features

- 🎲 Random number generation
- 🎮 Interactive console gameplay
- 📈 Hints after every guess (Too High / Too Low)
- 🔁 Unlimited guessing attempts
- 🏆 Displays total attempts after winning
- 💻 Lightweight and easy to understand
- 🚀 Great project for C++ beginners

## 🎮 How to Play

1. Run the program.
2. The computer randomly selects a secret number.
3. Enter your guess.
4. The program compares your guess with the secret number.
5. If your guess is incorrect, you'll receive one of the following hints:
   - 📉 Too Low
   - 📈 Too High
6. Continue guessing until you find the correct number.
7. The game displays the total number of attempts taken to win.
